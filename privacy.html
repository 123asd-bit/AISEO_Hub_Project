SITE POLICY

Privacy Notice

Transparency note: AISEO Hub is an educational SEO project hosted as a static website on Render over HTTPS.

Tool inputs

The included generators (Blog Title Generator, Meta Description Helper, Keyword Ideas, Content Outline Builder, and SEO Checklist) run entirely inside your browser using local JavaScript and do not transmit your form inputs to an external database.

Hosting and server logs

Static pages are served through Render and Cloudflare CDN over HTTPS. Standard web server and CDN request logs (such as IP address, browser user-agent, and requested URL) may be processed temporarily for delivery, caching, and security protection.

Analytics and third-party services

This website uses Google Analytics 4 (Measurement ID: G-LRX1NDMSGD) and Google Search Console to measure aggregated page views, site health, and outbound link interactions. No personal accounts or logins are required to use any page or tool.

Project ownership

AISEO Hub is maintained as an academic SEO mini-project by Team Codecrafters (SEO190). You can learn more on our About page.
